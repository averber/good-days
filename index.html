To share this log with your husband, set up one free shared database and enter the same URL on both phones:

1. Go to console.firebase.google.com and create a free project.
2. Open Build → Realtime Database → Create Database → start in test mode.
3. In the Rules tab, set both .read and .write to true, then publish (so it doesn't expire in 30 days).
4. Copy the database URL shown on that page and paste it above, on both phones.

Once connected, entries sync automatically every ~20 seconds, and right away when you tap "Sync now." Anyone with the URL could read or write to it, so don't share it beyond your household.

Your data

Everything is stored privately in this browser, on this device only — nothing is sent anywhere, unless you connect sync above. If you clear your browser data or switch devices without syncing, this log won't carry over unless you export it first.

About this scale

HHHHHMM (Hurt, Hunger, Hydration, Hygiene, Happiness, Mobility, More good days than bad) is a veterinary quality-of-life framework popularized by Dr. Alice Villalobos, used to support — not replace — conversations with your vet.
